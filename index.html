Data Visualization

Tableau Health Dashboard

Objective

Build an interactive dashboard to explore and communicate health-related indicators clearly, at a glance.

My Role

Data analysis, calculated field design, and end-to-end dashboard layout in Tableau.

Process

Explored a dataset of 4,155 records covering fields such as Age, BMI, Systolic/Diastolic BP, Total/HDL/LDL Cholesterol, Triglycerides, Smoking Status and Physical Activity Level. Built calculated fields including BP Risk Category, BMI Category, Cholesterol Ratio, Pulse Pressure and BMI-Age Interaction, then organized them into KPI cards and supporting visualizations.

Tools

Tableau, data analysis, calculated fields, dashboard design.

Output

A multi-view dashboard with KPI summaries and breakdowns by age group, BMI category and BP risk category.

Value

Turned a wide, technical dataset into a dashboard that's readable and useful for non-technical viewers.

Front-End Development

AirPlanes Travel Website

Objective

Build a multi-page airline & travel booking platform that simulates a complete booking journey, end to end.

My Role

Front-end development across all pages — structure, styling and page-to-page interactivity.

Process

Built out connected flows for home search, travel packages, date selection, flight listing and selection, seat map booking, hotel booking, and ticket/receipt generation, alongside login, signup and profile pages — all sharing a consistent navigation, header and footer across 13 pages.

Tools

HTML, CSS, JavaScript.

Output

A connected 13-page site covering two full journeys: flight booking (search → dates → flights → seats → ticket) and package booking (packages → hotels → receipt), plus account pages.

Value

Hands-on practice architecting a larger multi-page front-end project with shared components and several interactive flows, including dynamic seat selection and pricing.
